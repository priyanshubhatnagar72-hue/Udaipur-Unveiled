# Udaipur Unveiled: The Royal Guide

A elegant, responsive landing page dedicated to the tourism of Udaipur, Rajasthan. This project features a sophisticated "Royal Mewar" aesthetic using a rich palette of crimson and gold, paired with classic serif typography.

## 🌟 Features

- **Royal Aesthetic:** Custom color scheme (#800000 and #daa520) reflecting the heritage of Rajasthan.
- **Responsive Grid:** A flexible card-based layout for attractions that adapts to mobile, tablet, and desktop screens.
- **Interactive Navigation:** Smooth-scrolling navigation bar for a seamless user experience.
- **Detailed Itinerary:** Styled components for travel plans with a classic framed border effect.
- **Modern Typography:** Integrated Google Fonts (*Playfair Display* and *Lora*) for a high-end editorial look.

## 🛠️ Built With

- **HTML5:** Semantic structure.
- **CSS3:** Custom styling, Flexbox, CSS Grid, and pseudo-elements for decorative borders.
- **JavaScript:** Smooth scroll functionality for anchor links.
- **Google Fonts:** Premium typography integration.

## 📁 File Structure

- `index.html`: The main entry point containing the structure, styles, and scripts.

## 🚀 How to Use

1. **Clone or Download:** Save the code into a file named `index.html`.
2. **Open:** Open the file in any modern web browser (Chrome, Firefox, Safari).
3. **Customize:**
   - Change the `background: url(...)` in the `.hero` class to update the main header image.
   - Edit the `.places-grid` cards to add or remove attractions.

## 🎨 Customization Tips

- **Colors:** You can change the `--primary-color` and `--accent-color` in the `:root` section of the CSS to match a different city or brand theme.
- **Images:** All images are currently linked via external URLs. For production, it is recommended to host these images locally for better reliability.
